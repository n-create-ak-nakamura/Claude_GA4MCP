プライバシーポリシー

制定日：2026年9月29日

本ポリシーは、個人用ツール「Claude Analytics Access」（以下「本ツール」）における Google ユーザーデータの取り扱いを定めるものです。

1. 利用者

本ツールは開発者本人のみが利用する個人用ツールであり、第三者には提供していません。

2. 取得する情報

本ツールは、利用者が Google アカウントで許可した範囲で、次の情報を読み取り専用で取得します。

  • Google アナリティクス 4：利用者がアクセス権を持つアカウント・プロパティの一覧と、レポートの集計データ（analytics.readonly）
  • Google Search Console：利用者がアクセス権を持つサイトの一覧と、検索パフォーマンスの集計データ（webmasters.readonly）

データの作成・変更・削除は行いません。

3. 利用目的

取得した情報は、利用者自身の業務における分析・レポート作成のためにのみ使用します。広告・販売・プロファイリングなど、他の目的には使用しません。

4. 保存と第三者提供

  • 取得したデータは、分析の都度 API から読み出して使用し、本ツールが独自のサーバーに保存・蓄積することはありません。
  • 認証情報（OAuth のリフレッシュトークン等）は、利用者自身が管理する環境の環境変数・設定ファイルにのみ保存します。
  • 取得したデータを第三者に販売・提供することはありません。分析のために、利用者が契約する AI アシスタント（Anthropic 社の Claude）にデータが渡される場合があります。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本ツールによる Google API から取得した情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に準拠します。

6. アクセス権の取り消し

本ツールへのアクセス許可は、Google アカウントのサードパーティ製アプリのアクセス管理ページからいつでも取り消せます。

7. お問い合わせ

本ポリシーに関するお問い合わせ：ak-nakamura@n-create.co.jp

Privacy Policy (English summary)

Claude Analytics Access is a personal tool used only by its developer. With the user's consent, it reads Google Analytics 4 and Google Search Console data using read-only scopes (analytics.readonly, webmasters.readonly). It never creates, modifies or deletes data. Retrieved data is used only for the developer's own analysis and reporting, is not stored on any server operated by this tool, and is not sold or shared with third parties, except that it may be passed to the AI assistant the developer uses (Anthropic's Claude) for analysis. OAuth credentials are kept only in environment variables or configuration files managed by the user. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: ak-nakamura@n-create.co.jp
